# Leni'z | Luxury Eau De Parfum

A sleek, premium landing page designed for a high-end fragrance brand. This project focuses on modern web design principles, featuring a dark luxury aesthetic, smooth CSS animations, and a fully responsive layout without the need for JavaScript.

## ✨ Features
* **Modern UI/UX:** Dark mode aesthetic with elegant gold (`#d4af37`) typography and accents.
* **Pure CSS Animations:** Features keyframe animations including a floating perfume bottle and smooth fade-up load effects.
* **Glassmorphism:** Utilizes CSS backdrop-filters to create premium, frosted-glass interface elements.
* **Fully Responsive:** Fluid layout built with CSS Grid and Flexbox, adapting seamlessly to desktop, tablet, and mobile screens.
* **Zero Dependencies:** Built entirely with vanilla HTML5 and CSS3.
